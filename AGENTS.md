# Agent routing and repository rules

This repository is a cluster agnostic Slurm evidence deployment kit. For deployment read README.md, docs/deployment.md, docs/hooks.md, docs/operations.md, docs/acceptance.md, docs/handover.md and AGENT_HANDOFF.md. Continue authorized preparation, installation and commissioning, obtaining only missing target inputs. Store private config, receipts, raw logs and credentials outside Git.

For repository work read CONTRIBUTING.md and docs/factory.md. All changes go through a merge request. Run tools/run_tests.py, tools/check_repository.py and Python compilation before publication; humans approve and merge. Never claim a fixture, boot-enabled unit or healthy browser proves complete capture or actual reboot survival.

Use explicit cluster/epoch identity, approved readable roots, durable terminal/accounting sources and source retention. Preserve existing scheduler hooks/plugins. Do not add customer names, live hosts/addresses, inventories, job histories, deployed-reference code, secrets, data lakes, exports or dependency binaries. The intake source stays outside both Git history and distributable bundles.

Protect collector state/payloads during updates. Do not reset job IDs, reboot/reset customer nodes, widen access, fabricate qualification outcomes or upload data to a hub without that operational scope. Preserve gaps, redaction provenance and supported identity/file-size limits. Match documentation to the actual installer/renderer and maintain recovery/noninterference tests when behavior changes.
